### What is Ovecc

Ovecc turns your repository into a deterministic architecture graph.

It lets you query impact, drift, coupling, and ownership directly from the CLI, with no dashboards and no guesswork.

Built in Rust for speed, reliability, and scale.

---

### Core idea

Repository → deterministic analysis → architecture database → actionable insights
