### What is Ovecc

Ovecc is a CLI-first architecture intelligence engine that turns your codebase into a living, queryable model of dependencies, ownership, and evolution, continuously revealing how changes propagate, where systems are becoming brittle, and where technical debt is accumulating so engineering teams can understand and control the real architectural impact of AI-era software development before it becomes costly to fix.

---

### Core idea

Repository → deterministic analysis → architecture database → actionable insights
